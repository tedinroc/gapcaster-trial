# GapCaster 試用網站（給 Ted 的說明）

這個資料夾會整個放上 GitHub Pages（`https://tedinroc.github.io/gapcaster-trial/`），**裡面的每個檔案都是公開的**。不要放任何私人資料：參加者的名字、聯絡方式、回覆、付款資料都只能放在 `stage2/pilot-private/`（見最後一節）。**任何含撰稿人文字的檔案（核可版匯出、`*_edited.wav`、`pilot_log.json`、用撰稿人文字做的音檔或影片）也絕對不放進這個資料夾**（見「撰稿人的文字不公開」）。

網站是純靜態的：不收資料、沒有表單服務、沒有網站流量分析工具、沒有第三方程式或字型。審閱頁以外的每一頁都有 Content-Security-Policy，`connect-src 'none'`，所以這些網頁連想送資料出去都做不到。審閱頁（`review/`）是 GapCaster 產生的頁面，**沒有 CSP**；它的程式裡沒有任何網路呼叫（沒有 fetch、XMLHttpRequest、sendBeacon、WebSocket，也沒有外部網址），但這是看程式碼得到的，不是瀏覽器強制的。對外說明時不要說「每一頁都有 CSP」。資料只會在參加者自己複製結果碼、或下載檔案後，由他們用 email 或 LINE 傳給你。

## 結果碼格式（聽眾）

```
GapCaster 聆聽結果 v2
代號 L03｜素材 m1｜2026-11-26
B先前 沒有
B無 懂3
B一 懂4 內4 聲5 蓋3 整4 想4
B理解 （聽眾的回答）
A先前 不確定
A無 懂2
A一 懂4 內4 聲4 蓋3 整4 想4
A理解 不知道
英語 聽得懂一部分
聽法 自己用聆聽網頁播放
備註 -
未答 0 題
```

- 上面的數字和答案是格式示意，不是資料。
- **v2（11/23）和 v1 的差別**：第二行不再有輪次（v2 只有一輪，就是評估協定裡的第 1 輪）；每段片多一行「先前」；沒有「二」那一行。v1 從來沒有參加者用過。
- `先前`＝「在這次試用以前，有沒有聽過這段片的口述影像，或讀過、審閱過它的口述影像稿」：`沒有`、`有`、`不確定`，`-` 是沒答。事先公開的規則：`有` 的那段片（B 或 A），這位聽眾那段片的各行不放進主要分析，只報人數；`不確定` 照常放進分析，另外報人數；沒答（`-`）和 `不確定` 一樣照常放進分析，另外報沒答的題數（評估協定修正 1）。
- `無`＝沒有口述影像的版本；`一`＝有口述影像的版本（R16 原始草稿，公開的 `media/<片段>_ad.mp3`）。「一」這個字是沿用 v1 的標記，沒有「二」。
- 懂＝看懂、內＝內容、聲＝聲音清楚、蓋＝沒蓋到（5 分＝完全沒蓋到，越高越好）、整＝整體、想＝想再看。`-` 是沒答。
- `素材` 是公開音檔的版本（`assets/listen.js` 的 `MEDIA_VERSION`，目前 `m1`）。
- `未答` 把「先前」也算進去（`備註` 不算）。
- 換行的文字會變成「 / 」，所以一行就是一個項目。

撰稿人最後問題的回信格式（v2，在 `questions.md` 最後一節）：

```
GapCaster 撰稿人問題 v2
代號：W__
省力_ 正確_ 想用_
A先前_ B先前_
備註：（可不填）
```

`A先前`、`B先前` 填「沒有」「有」或「不確定」，規則和聽眾一樣：回答「有」的那段片，這位撰稿人那段片的資料不放進主要分析，只報人數；「不確定」和留空照常放進分析，另外報人數。

同意回覆的格式（v2，`consent.md` 第 12 節，`assets/consent.js` 照同一份產生）：第二行是「代號：W03｜撰稿人」，沒有輪次；也沒有「第二輪聽眾聽我的修改版」那一行。

撰寫頁下載的 JSON：`round` 一律是 `1`、`page_version` 是 `v2`（格式 `gapcaster-write/1` 沒變）；`active_seconds` 是扣掉暫停後的計時秒數（分析用這個），`started_at`、`finished_at` 是第一次按開始和按完成的時間，`timer_note` 是參加者自己寫的計時備註，`lines` 是解析出來的有時間的句子，`unparsed_lines` 是格式不符的行（原文都在 `text`）。

## 用 iPhone VoiceOver 測試（15 分鐘）

開關：設定 > 輔助使用 > VoiceOver（或設定好「輔助使用快速鍵」後連按三下側邊按鈕）。手勢：向右或向左滑動＝下一個或上一個項目；點兩下＝啟用；兩指旋轉＝轉子（選「標題」後上下滑動可以跳標題）；三指滑動＝捲動。
