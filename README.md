# GapCaster 試用網站（給 Ted 的說明）

這個資料夾會整個放上 GitHub Pages（`https://tedinroc.github.io/gapcaster-trial/`），**裡面的每個檔案都是公開的**。不要放任何私人資料：參加者的名字、聯絡方式、回覆、付款資料都只能放在 `stage2/pilot-private/`（見最後一節）。**任何含撰稿人文字的檔案（核可版匯出、`*_edited.wav`、`pilot_log.json`、用撰稿人文字做的音檔或影片）也絕對不放進這個資料夾**（見「撰稿人的文字不公開」）。

網站本身是靜態的（GitHub Pages），沒有網站流量分析工具、沒有第三方程式或字型。**v3（11/23）起有一個例外：「送出」按鈕。**參加者按下「送出作答」「送出撰寫內容」「送出記錄」或「送出回答」時，那一頁的作答會用一次 POST 傳到你 tedinroc Cloudflare 帳號上的收件伺服器（inbox，`https://gapcaster-trial-inbox.pages.dev/api/submit`）。按下以前什麼都不送，也不會自動重送。整個網站只有 `assets/common.js` 的 `GC.send()` 一處會連網路，網址只寫在同一個檔案的 `GC_INBOX` 常數裡（`check.py` 會擋其他地方）。

- 會送出的頁面（`listen.html`、`write.html`、`final.html`）的 Content-Security-Policy 是 `connect-src https://gapcaster-trial-inbox.pages.dev`，只准連到收件伺服器；其他頁面（首頁、同意書、題目稿、參加頁、工作清單）照舊 `connect-src 'none'`，連想送資料都做不到。
- 審閱頁（`review/`）是 GapCaster 產生的頁面。11/23 加上「送出記錄」（見「審閱頁」），它載入 `../../assets/common.js` 和 `../../assets/review-send.js`，所以審閱頁現在**有**網路呼叫：按「送出記錄」時，經 `GC.send()` 送到同一個收件伺服器。11/23 第二次修改（`tools/patch_review.py` 第 2 步）也給審閱頁加上 CSP：`connect-src` 只准連到收件伺服器；因為頁面有自己的內嵌程式和樣式，`script-src`、`style-src` 允許 `'unsafe-inline'`（不用算雜湊），`img-src` 允許 `data:`（句子的縮圖）。這個 CSP **還要在真的瀏覽器上確認**（開始計時、播放影片和字幕、逐句語音、完成並下載、送出記錄），見「審閱頁」第 6 步。不要再說「網站不會送出資料」。
- 送不出去的時候，照舊可以複製結果碼、下載檔案，用 email 或 LINE 傳給你。

### 送出的資料（收件伺服器，v3）

每一次送出都是一個 JSON（收件伺服器的 API v1，和收件伺服器那邊的說明相同）：

```
{"v":1, "kind":"listen", "code":"OL-7K3QX", "mode":"open", "round":1, "page":"listen v3",
 "client_time":"2026-11-26T06:03:05.123Z", "payload":{…},
 "consent":{"version":"v3","items":["年滿 18 歲","讀過試用同意書 v3","同意參加","了解公開參加沒有酬勞","不在作答裡寫姓名或聯絡方式"],"at":"2026-11-26T05:20:41.000Z"}}
```

- `kind`：`listen`（聆聽頁）、`write`（撰寫頁）、`review`（審閱頁）、`writer-final`（最後的問題）。`consent` 這種 kind 網站沒有用到：同意紀錄附在每一次送出裡。
- `mode`：代號是 `OL-`／`OW-`（測試是 `TOL-`／`TOW-`）開頭就是 `open`，其他是 `invited`。分析時以代號為準。
- `client_time`、`consent.at` 都是 UTC（`toISOString`），不帶裝置的時區。
- `consent`：只有公開參加的代號才有。這臺瀏覽器或連結裡找不到時，頁面會先請參加者在送出按鈕上方再勾一次 5 項，所以公開代號的每一次送出都有。撰稿人另外有第 7 節的選擇，例如 `"選項 A：可以放進作品"`、`"選項 A-1：願意"`、`"選項 B：不要"`。
- `page`：`listen v3`、`write v3`、`final v3`、`review-pilot-1 A-2 row3`（審閱頁加上資料夾和列；不知道列時沒有 `row`）。
- 伺服器收到後回 `{"ok":true,"id":"<10 個字>","received_at":"<UTC>"}`，頁面顯示「已送出。收件編號 …，伺服器收到的時間 …（臺北時間）」，也記在這臺裝置上（`gc-receipt-v3:…`），工作清單會標「這臺裝置已送出」。

`payload`：

- **listen**：`{"format":"gapcaster-listen/1","page_version":"v3","media_version":"m1","answers":{…},"unanswered":3,"result_text":"GapCaster 聆聽結果 v3\n…"}`。`answers` 是 `{"vision":"全盲","B":{"exposure":"沒有","no_ad":{"understood":3},"ad":{"understood":4,"content":4,"clarity":5,"not_covered":3,"overall":4,"want_more":4},"comprehension":"…"},"A":{…同上…,"english":"聽得懂一部分"},"method":"自己用聆聽網頁播放","comment":"…"}`；1 到 5 分是數字，其他是選項文字，沒答是 `null`。對照：understood＝懂、content＝內、clarity＝聲、not_covered＝蓋、overall＝整、want_more＝想。
- **write**：撰寫頁的 JSON（見上）。
- **review**：審閱頁的 `pilot_log`（`schema: gapcaster.pilot_log/1`），和「完成並下載」的檔案完全相同。
- **writer-final**：`{"format":"gapcaster-writer-final/1","page_version":"v3","row":3,"answers":{"effort":4,"accuracy":3,"would_use":5,"exposure":{"A":"沒有","B":"不確定"},"trained":"有","comment":"…"},"unanswered":0,"reply_text":"GapCaster 撰稿人問題 v3\n…"}`。effort＝省力、accuracy＝正確、would_use＝想用。
- 同一個代號、同一種 kind 送出不只一次時，用伺服器在試用時間內收到的最後一筆（審閱頁和撰寫頁是每個半段各算各的）。

## 用 iPhone VoiceOver 測試（15 分鐘）

開關：設定 > 輔助使用 > VoiceOver（或設定好「輔助使用快速鍵」後連按三下側邊按鈕）。手勢：向右或向左滑動＝下一個或上一個項目；點兩下＝啟用；兩指旋轉＝轉子（選「標題」後上下滑動可以跳標題）；三指滑動＝捲動。

1. （2 分鐘）用 Safari 打開 `.../listen.html#code=T01&round=1`。應該聽到頁面標題和「你的代號：T01。」
2. （2 分鐘）轉子選「標題」，往下跳：要依序聽到「開始之前」「先回答：視力狀況」「片段 B：《Spring》」「B：聽之前先回答」「B：先聽，沒有口述影像的版本」「B：再聽，有口述影像的版本」「B：理解題」……「最後兩題」「送出」「結果碼（送不出去的時候用）」。

4. （2 分鐘）到「B：理解題」的文字框，點兩下，用聽寫或鍵盤輸入一句話，確認提示文字有被讀出。
5. （3 分鐘）跳到「送出」，點兩下「送出作答」，應該聽到「正在送出」，接著「已送出。收件編號……」。再跳到「結果碼」，點兩下「複製結果碼」，應該聽到「已複製結果碼……」。如果有「分享結果碼（手機）」按鈕，也試一次分享到 LINE。也用 VoiceOver 走一次參加頁 `join.html#test=1`：選聽眾、勾 5 項、按「同意並取得代號」，應該跳到「你的代號」，並能聽到一個字一個字唸的代號。
6. （3 分鐘）打開 LINE，貼到 Keep 筆記或只有自己的聊天室，確認整段結果碼完整。不要傳給別人。回到 Safari，確認作答還在（頁面會說「已恢復……」）。最後按「清除這臺裝置上的作答」，確認有確認對話框和清除完成的提示。

通過以後，可以把 `index.html` 對螢幕閱讀器的說法改成「已用 iPhone VoiceOver 測試」（見上面第 17 點）。有問題就記在 `stage2/pilot-private/voiceover-test.md`（不要放進這個資料夾），交給 Claude 修。Claude 沒辦法在真的 VoiceOver、TalkBack、NVDA 上測，只能離線檢查結構；有 Android 手機或 Windows 電腦的話，用 TalkBack（Chrome）或 NVDA（Firefox 或 Chrome）照同樣步驟走一次更好。

## 已知限制
